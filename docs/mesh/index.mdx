# 근무안심

근무안심(Mesh)은 국내 및 해외 사업장의 파트타이머 일정을 관리하는 관리자를 위한 Apps in Toss WebView 기반 근무 일정 관리 앱입니다.
초기 버전은 서버 없이 로컬 기기 안에서 사업장, 근무 유형, 근무자, 일정, 불참, 대타 배정을 관리해요.

## 한 줄 설명

근무안심은 매장 관리자가 월간 캘린더에서 근무자를 배치하고, 불참이 생겼을 때 대타 후보를 빠르게 찾는 로컬 우선 일정 관리 앱이에요.

## 문제 정의

파트타이머 일정 관리는 일정 등록보다 예외 처리에서 시간이 많이 들어요.
누가 어떤 역할을 할 수 있는지, 같은 시간에 이미 근무가 있는지, 불참한 자리를 누가 대신할 수 있는지를 관리자가 즉시 판단할 수 있어야 해요.

## 대상 사용자

- 식당, 카페, 편의점, 매장, 서비스업에서 파트타이머를 관리하는 관리자
- 하나 이상의 사업장을 운영하며 사업장별 역할과 일정을 분리해서 보고 싶은 사용자
- 복잡한 인사 시스템보다 모바일에서 빠르게 근무표를 정리하고 싶은 사용자

## 핵심 가치

- 첫 사용자는 사업장 이름, 규모, 국가만 순차적으로 입력하고 시작해야 해요.
- 일정, 근무 유형, 근무자, 사업장 데이터는 현재 선택된 사업장을 기준으로 완전히 분리해야 해요.
- 기본 일정 등록은 단일 일정 중심이고, 반복 일정은 사용자가 체크했을 때만 확장 UI를 보여줘야 해요.
- 대타 후보는 원래 해당 근무 유형을 할 수 있는 사람을 먼저 보여주되, 다른 근무자도 예외 후보로 볼 수 있어야 해요.
- 현재 근무자는 강조하고, 불참한 원래 근무자는 연하게 표시해야 해요.
- UI는 한국어, 24시간제, Apps in Toss WebView, 최대 가로 800px 기준을 따라야 해요.

## 현재 상태

2026년 5월 25일 기준으로 PRD, Apps in Toss WebView 스캐폴드, 로컬 저장 기반 MVP 화면, 하네스 지식, 브랜치 보호 훅, GitHub Actions 번들 업로드 워크플로우가 준비돼 있어요.
서버 연동, 로그인, 클라우드 백업, 직원용 앱, 푸시 알림은 백로그예요.
