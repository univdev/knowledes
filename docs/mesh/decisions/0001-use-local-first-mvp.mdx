# 로컬 우선 MVP로 시작하기

## 상태

채택됨

## 날짜

2026-05-25

## 배경

근무안심은 관리자용 일정 관리 앱으로 시작해요.
초기 목표는 직원용 협업 앱이나 클라우드 인사 시스템을 만드는 것이 아니라, 관리자가 빠르게 사업장, 근무 유형, 근무자, 일정을 등록하고 대타를 찾는 경험을 검증하는 것이에요.

## 결정

초기 MVP는 서버 없이 로컬 저장 기반으로 구현해요.
로그인, 클라우드 백업, 직원용 앱, 서버 연동, 푸시 알림은 백로그로 둬요.

## 고려한 대안

- 처음부터 로그인과 서버 동기화를 포함하기
- 공유 문서나 파일 백업으로 데이터를 내보내게 하기
- 직원용 앱을 함께 만들어 불참과 대타 신청을 직원이 직접 처리하게 하기

## 선택 이유

사용자는 일반 사용자가 쓰기 어려운 백업/동기화 방식보다 단순한 관리자용 앱을 원했어요.
서버를 붙이면 계정, 권한, 동기화 충돌, 백업, 개인정보 처리 범위가 커져 MVP 속도가 느려져요.
따라서 먼저 관리자가 혼자 쓰는 로컬 앱으로 핵심 일정을 검증하는 편이 적합해요.

## 트레이드오프

기기를 바꾸거나 여러 관리자가 함께 쓰는 상황은 MVP에서 해결하지 못해요.
데이터 백업과 복구도 자동으로 제공되지 않아요.
이 제약은 향후 로그인과 클라우드 백업을 추가할 때 다시 결정해야 해요.

## 결과와 후속 작업

현재 구현은 로컬 저장과 사업장별 데이터 분리를 기준으로 설계돼요.
서버 연동을 추가할 때는 기존 로컬 데이터 모델을 마이그레이션할 수 있는 경로가 필요해요.
