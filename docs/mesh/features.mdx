# 주요 기능

## 온보딩

최초 사용자는 사업장 정보를 순차 입력해요.
한 화면에 모든 입력을 몰아넣지 않고, 하단 safe area를 고려한 전체 폭 CTA로 다음 단계로 이동해요.

입력 항목은 사업장 이름, 사업장 규모, 사업장 국가예요.
국가는 전체 국가 리스트에서 선택하고, 선택한 국가를 기준으로 시간대를 저장해요.

## 일정

일정 탭은 월간 캘린더가 화면의 중심이에요.
상단 타이틀, 하단 FAB, 탭바를 제외한 영역을 캘린더가 최대한 차지해야 해요.

캘린더는 이번 달을 기본으로 보여주고, 상하 스와이프로 이전 달과 다음 달을 탐색해요.
날짜 셀에는 어떤 근무자가 어떤 역할로 일하는지 간단히 표시해요.

표시 규칙은 다음과 같아요.

- 한 명만 있으면 이름과 역할을 함께 보여줘요.
- 같은 역할에 여러 명이 있으면 역할명과 인원 수로 요약해요.
- 대타가 배정된 일정은 현재 근무자를 강조하고 원래 근무자는 연하게 보여줘요.

## 근무 유형

근무 유형은 사업장별로 관리해요.
등록된 유형은 가로로 길고 세로로 짧은 카드 목록으로 보여주고, 추가는 우하단 FAB에서 시작해요.

근무 유형에는 이름과 색상이 필요해요.
색상은 20개 고정 팔레트를 18px 원형 버튼으로 제공하고, 사용자가 직접 선택해요.
선택 시간대는 optional이며 여러 개를 등록할 수 있어요.

## 사업장

한 관리자가 여러 사업장을 관리할 수 있어요.
사업장을 선택하면 일정, 근무 유형, 근무자 데이터가 해당 사업장 기준으로 전환돼요.

사업장 추가와 수정에는 이름, 규모, 국가를 입력해요.
규모 범위는 경계가 겹치지 않도록 `2~5인`, `6~10인`, `11~50인`, `51~100인`, `101인 이상`을 사용해요.

## 근무자

근무자 탭에서는 현재 사업장의 근무자를 목록으로 보고 등록해요.
등록 항목은 이름, 성별, 전화번호, 이메일, 가능한 근무 유형이에요.
전화번호와 이메일은 선택사항이에요.

근무 유형이 없는 상태에서 근무자를 등록하려고 하면 근무 유형 추가로 이동할 수 있어야 해요.
근무자 삭제 시 해당 근무자가 소속된 역할과 배치된 일정에서도 함께 제거돼요.

## 대타 구하기

불참 선언된 일정을 누르면 수정, 삭제, 대타 구하기 액션을 제공해요.
대타 구하기는 같은 근무 유형을 할 수 있고 해당 시간대에 근무 기록이 없는 사람을 먼저 보여줘요.
그 외 사람들도 예외 후보로 표시해, 주방 담당자가 서빙 대타를 맡는 현실적인 상황을 허용해요.

후보를 누르면 전화 걸기와 대타로 등록하기를 보여줘요.
전화 걸기는 전화번호가 등록된 근무자에게만 보여줘요.

## 필터와 검색

검색과 필터는 우상단 필터 아이콘에서 열리는 우측 Drawer로 제공해요.
바텀시트가 아니라 오른쪽에서 들어오는 Drawer를 사용해 일정/근무자 목록의 맥락을 유지해요.
