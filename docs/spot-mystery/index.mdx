# Spot Mystery

Spot Mystery는 한국어 서비스명 `미스테리 어드벤처`로 개발 중인 Apps in Toss WebView 미니앱입니다.
전세계 사건사고 스팟, 폐허, 심령 장소, 신비로운 자연 스팟을 지도와 검색 흐름으로 탐험하게 만드는 것이 목적입니다.

## 한 줄 설명

전세계 미스테리 장소의 위치, 이야기, 이미지, 거리 정보를 모바일 지도와 검색 리스트로 탐험하는 앱인토스 미니앱입니다.

## 문제 정의

미스테리 장소 콘텐츠는 흩어진 글, 영상, 지도 정보로 소비되는 경우가 많습니다.
사용자는 장소의 배경 이야기와 위치 맥락을 함께 보고 싶지만, 일반 지도 앱은 이야기성이 약하고 일반 콘텐츠 앱은 위치 기반 탐험성이 약합니다.

Spot Mystery는 다음 문제를 해결합니다.

- 장소의 위치와 이야기를 한 화면 흐름 안에서 연결합니다.
- 사건사고, 공포, 신비, 폐허 같은 테마를 태그로 구분합니다.
- 현재 위치 기준 거리와 지도 마커를 통해 탐험의 감각을 제공합니다.
- 검색 전에는 `가장 유명한 스팟 TOP 10`을 보여줘 시작점을 만듭니다.

## 대상 사용자

- 전세계 미스테리 스팟과 폐허에 관심 있는 사용자
- 지도 기반으로 낯선 장소를 탐험하고 싶은 사용자
- 사건 배경과 장소 정보를 함께 읽고 싶은 사용자
- 앱인토스 안에서 가볍게 탐험형 콘텐츠를 소비하려는 사용자

## 핵심 가치

- 첫 화면에서 무엇을 하는 앱인지 즉시 보여야 합니다.
- 공포만 강조하지 않고 신비로운 탐험감을 유지해야 합니다.
- 한 화면의 주요 강조 요소는 1~2개로 제한합니다.
- 모바일 첫 뷰포트에서 핵심 선택지가 과도하게 노출되지 않아야 합니다.
- AIT 설정에는 사용자가 업로드 URL을 제공하기 전까지 빌드에 묶인 로고 파일을 넣지 않습니다.

## 현재 상태

2026-06-14 기준 초기 MVP 개발이 완료되었습니다.

- React + Vite + TypeScript 기반 WebView 앱
- Tailwind CSS + daisyUI 기반 디자인 시스템
- Pretendard 기본 폰트 설정
- React Router 기반 `onboarding`, `explore`, `search` 라우팅
- Vitest 단위 테스트와 Playwright e2e 테스트 추가
- Playwright 기반 UI 복잡도 스냅샷 측정 추가
