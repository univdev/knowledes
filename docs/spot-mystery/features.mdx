# 주요 기능

## 온보딩

### 목적

첫 접속 사용자가 앱의 탐험형 성격을 즉시 이해하게 합니다.

### 사용자 흐름

1. 사용자는 첫 진입 시 온보딩으로 이동합니다.
2. 세 개의 튜토리얼 슬라이드를 `NEXT`로 넘깁니다.
3. 마지막 슬라이드에서 `START`를 누르면 탐험 화면으로 이동합니다.
4. `SKIP`을 누르면 즉시 탐험 화면으로 이동합니다.

### 문구

- `흥미진진한 모험이 기다려요`
- `장소에 얽힌 이야기를 읽어봐요`
- `우리 주변에도 있을지 몰라요`

## 탐험

### 목적

사용자 위치 기준으로 대표 미스테리 스팟을 지도에서 탐험하게 합니다.

### 사용자 흐름

1. `/explore`에 진입합니다.
2. 앱은 위치 권한을 요청합니다.
3. 위치 권한이 없으면 서울 기준으로 거리를 계산합니다.
4. 지도 위 대표 마커를 누르면 상세 바텀시트가 열립니다.

### UI 제약

초기 지도 화면의 선택지는 대표 마커 4개와 하단 탭 2개로 제한했습니다.
이는 한 화면의 핵심 선택지를 5개 이하로 권장한 UX 복잡도 기준에 맞추기 위한 결정입니다.

## 찾기

### 목적

사용자가 취향에 맞는 장소와 이야기를 검색해서 찾게 합니다.

### 사용자 흐름

1. `/search`에 진입하면 `가장 유명한 스팟 TOP 10`을 보여줍니다.
2. 검색어를 입력하면 장소명, 국가, 위치명, 설명, 사건사고, 카테고리를 대상으로 필터링합니다.
3. 리스트 카드를 누르면 탐험 화면과 같은 상세 바텀시트가 열립니다.

## 상세 바텀시트

### 포함 정보

- 장소 이미지
- 장소명
- 국가와 위치 라벨
- 카테고리 태그
- 현재 위치 기준 거리
- 로드뷰 확인 가능성 메모
- 장소 설명
- 이 장소에 얽힌 사건사고
- 인근 부동산 또는 접근 비용 관련 메모

## 테스트 자동화

### 단위 테스트

Vitest로 거리 계산과 장소 검색 로직을 검증합니다.

### e2e 테스트

Playwright로 다음 흐름을 검증합니다.

- 온보딩 완료 후 탐험 탭 이동
- 탐험 지도 마커 선택 후 상세 바텀시트 열기
- 찾기 탭 TOP 10 표시, 검색, 결과 상세 열기
- 핵심 화면 스냅샷 촬영과 UI 복잡도 기준 통과
