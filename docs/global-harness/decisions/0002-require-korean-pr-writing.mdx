# PR 제목과 본문을 한국어로 작성하기

## 상태

채택됨

## 날짜

2026-05-26

## 배경

이전 작업에서 PR 제목과 본문이 영어로 작성됐어요.
사용자는 앞으로 PR을 한국어로 남기기를 원했어요.

전역 하네스에는 이미 PR 작업을 `pull-request-manager`에게 위임하는 규칙이 있었어요.
따라서 PR 언어 규칙도 오케스트레이터와 PR 전담 에이전트 양쪽에 명시해야 했어요.

## 결정

PR 제목과 본문은 기본적으로 한국어로 작성해요.
한국어 사용자-facing 문맥을 가진 프로젝트에서는 부드러운 Toss식 `-요`체를 선호해요.

프로젝트가 명시적으로 다른 언어를 요구하거나 사용자가 직접 다른 언어를 요청한 경우만 예외로 둬요.

## 고려한 대안

- 프로젝트별로 PR 언어를 따로 정하기
- Apps in Toss 프로젝트에만 한국어 PR을 강제하기
- PR 언어를 에이전트 판단에 맡기기

## 선택 이유

여러 프로젝트에서 같은 사용자가 같은 방식으로 리뷰하므로 기본 언어가 흔들리면 리뷰 비용이 늘어나요.
전역 기본값을 한국어로 두면 사용자가 별도로 지시하지 않아도 일관된 PR 기록이 남아요.

Apps in Toss처럼 한국어 사용자-facing 문맥이 강한 프로젝트는 `-요`체가 제품 문서와도 잘 맞아요.

## 트레이드오프

오픈소스 협업처럼 영어 PR이 더 자연스러운 프로젝트에서는 예외 처리가 필요해요.
그래서 저장소 로컬 규칙이나 사용자 명시 요청이 있으면 다른 언어를 허용하도록 했어요.

## 결과와 후속 작업

`pull-request-manager`는 PR 제목과 본문을 한국어로 작성하는 기본 규칙을 갖게 됐어요.
전역 오케스트레이터는 PR 작업을 위임할 때 이 스타일 제약을 함께 넘겨요.
