# 전역 하네스

전역 하네스는 로컬 컴퓨터 전체에서 Codex 작업 흐름을 조율하는 운영 규칙이에요.
개별 프로젝트의 `AGENTS.md`보다 먼저 넓은 기준을 제공하고, 반복되는 작업은 전용 서브에이전트로 넘겨요.

## 한 줄 설명

전역 하네스는 PR, 문서 적재, 기존 맥락 탐색, 스캐폴딩, UI 검토 같은 공통 작업을 자동으로 라우팅하는 로컬 오케스트레이션 계층이에요.

## 문제 정의

여러 프로젝트를 번갈아 작업하면 이전 결정, 문서 위치, PR 작성 방식, 보호 규칙을 매번 다시 기억해야 해요.
이 기억을 사람에게만 맡기면 PR을 영어로 작성하거나, 기존 지식 문서를 읽지 않고 구현을 시작하거나, 작업 후 문서 적재를 빠뜨릴 수 있어요.

전역 하네스는 이런 반복 실수를 줄이기 위해 공통 규칙을 한곳에 모아요.

## 대상 사용자

- 로컬 컴퓨터에서 Codex로 여러 프로젝트를 개발하는 사용자
- 기존 작업을 이어서 진행해야 하는 Codex 에이전트
- PR 작성, 문서 적재, 맥락 탐색을 일관되게 처리해야 하는 보조 에이전트

## 핵심 가치

- 기존 지식을 먼저 읽고 개발을 시작해요.
- 기능 추가, 수정, 삭제가 끝나면 Knowledes에 변경 맥락을 남겨요.
- PR 제목과 본문은 기본적으로 한국어로 작성해요.
- 오케스트레이터는 발동 조건과 위임만 담당하고, 상세 작업은 전용 서브에이전트가 처리해요.
- 문서와 PR은 신규 개발자도 이해할 수 있는 쉬운 문장으로 작성해요.
