# 주요 기능

## 타이머 흐름

기본값은 집중 25분, 짧은 휴식 5분, 긴 휴식 30분이에요.
`집중 -> 짧은 휴식`을 한 라운드로 보고, 4라운드를 마친 뒤 긴 휴식을 진행하면 한 사이클이에요.

초기 화면에는 시작 버튼만 주요 액션으로 보여줘요.
사용자가 시작하면 버튼은 멈추기로 바뀌고, 다음 구간 아이콘 버튼이 보조 액션으로 나타나요.
멈춘 상태에서는 이어하기로 같은 구간을 계속 진행해요.

긴 휴식이 완료되면 다음 사이클을 자동으로 시작하지 않아요.
사이클 완료 상태에서 정지하고, 사용자가 이어하기를 누르면 새 사이클의 집중 1라운드부터 시작해요.

## 자동진행과 수동진행

기본값은 자동진행이에요.
자동진행에서는 구간이 끝나면 다음 구간으로 바로 넘어가요.
수동진행에서는 구간이 끝난 뒤 사용자가 다시 시작해야 다음 구간이 시작돼요.

사용자에게는 긴 설명 버튼 대신 아이콘으로 보여줘요.
다만 토글 의미가 모호했기 때문에, 누를 때 하단 토스트로 다음 문구를 보여줘요.

- 자동진행: `다음 구간으로 자동 전환돼요`
- 수동진행: `구간이 끝나면 직접 시작해요`

## 스킵과 기록

다음 구간 버튼은 한 번이라도 타이머를 시작한 뒤에만 보여줘요.
스킵한 집중은 완료한 집중 수에 포함하지 않아요.
한 사이클 안에서 스킵이 한 번이라도 있으면 그 사이클은 완료한 사이클 수에 포함하지 않아요.

단, 스킵 전 실제로 지나간 집중, 짧은 휴식, 긴 휴식 시간은 누적 시간에 더해요.
차트의 누적 시간은 사용자가 실제로 앱을 실행한 시간을 보여주는 지표이기 때문이에요.

긴 휴식에서 스킵하면 `00:00`에 멈추는 것이 아니라 새 사이클의 집중으로 돌아가요.

## 세션 시간 조정

집중, 짧은 휴식, 긴 휴식 박스를 누르면 시간 조정 다이얼로그가 떠요.
각 구간 시간은 1분부터 60분까지 정수 분 단위로만 바꿀 수 있어요.

입력창 대신 `-`와 `+` 버튼을 사용해요.
Apps in Toss WebView에서 input 포커스 시 화면 확대가 발생할 수 있기 때문에, 버튼형 stepper가 더 안정적이에요.

버튼을 0.6초 이상 길게 누르면 숫자가 연속으로 바뀌어요.
반복 속도는 cubic-in 느낌으로 점점 빨라지고, 숫자가 실제로 바뀔 때마다 가벼운 햅틱을 줘요.
dim 영역을 눌러도 다이얼로그가 닫혀요.

## 사운드와 볼륨

틱톡음은 Web Audio API로 만든 1초 길이 버퍼를 loop로 재생해요.
실제 소리는 짧게 끝나도 버퍼 전체 길이를 1초로 유지하는 방향을 유지해야 해요.
나중에 화이트노이즈나 배경음을 같은 구조로 이식하기 위해서예요.

볼륨은 0부터 5까지 6단계예요.
볼륨 버튼을 누를 때마다 한 단계씩 올라가고, 5 다음에는 0으로 돌아가요.
아이콘만으로 단계를 모두 표현하기 어렵기 때문에, 화면 중앙에 blur 처리된 숫자 박스를 잠깐 보여줘요.

숫자 박스는 0.4초 fade in, 0.4초 fade out으로 나타나고 사라져요.
연타하면 숫자만 바뀌며 등장 애니메이션은 반복하지 않아요.
마지막 조작 뒤 1초 동안 추가 입력이 없으면 닫혀요.
상태 표시용이라 클릭을 방해하지 않도록 pointer event를 막아요.

## 종료음과 햅틱

구간이 끝나면 틱톡음과 별개로 종료 알림음을 재생해요.
집중과 짧은 휴식은 같은 기본 종료음을 쓰고, 긴 휴식은 다른 기본 종료음을 써요.

햅틱은 가능한 경우 Apps in Toss SDK를 사용해요.
집중과 짧은 휴식 종료에는 짧은 햅틱을 주고, 긴 휴식 종료에는 더 강한 성공 계열 햅틱을 줘요.
브라우저에서는 `navigator.vibrate`로 fallback해요.

모든 버튼에는 tick 계열의 가벼운 햅틱을 추가했어요.

## Canvas 물결

배경 물결은 현재 구간의 전체 시간과 경과 시간을 기준으로 viewport 높이에 맞춰 움직여요.
집중과 긴 휴식에서는 아래에서 위로 차오르고, 짧은 휴식에서는 찬 물이 빠지는 방식으로 내려가요.

세션 색상은 1초에 걸쳐 부드럽게 바뀌어요.
스킵처럼 진행률이 갑자기 바뀌는 경우에도 물결 높이가 1초 동안 보간돼요.
화면을 가득 채웠을 때 물이 화면 밖으로 나간 것처럼 보이지 않도록 최대 높이에 상단 여백을 둬요.

물결은 두 겹이에요.
뒤쪽 물결은 같은 색상에 낮은 opacity를 쓰고, 앞쪽 물결과 진폭과 위상이 다르게 흘러 입체감을 줘요.

## 차트

차트 페이지는 Chart.js를 사용해요.
타이머가 실행 중이어도 차트 페이지로 이동할 수 있고, 타이머는 계속 진행돼요.
앱 내부 뒤로가기 버튼은 만들지 않고 Toss 기본 네비게이션을 사용해 돌아와요.

표시하는 데이터는 다음과 같아요.

- 오늘 기준 최근 30일의 완료한 집중 수
- 오늘 기준 최근 30일의 완료한 사이클 수
- 최근 30일 누적 집중, 짧은 휴식, 긴 휴식 시간
- 최근 7일과 이전 7일 흐름을 비교한 짧은 문구

비교 대상 기록이 없으면 `지난주와 비슷한 흐름`처럼 잘못된 문구를 보여주지 않아요.
처음 시작하는 사용자에게는 첫 집중을 유도하는 문구를 보여줘요.

누적 시간은 `0분`, `1시간`, `1시간 15분`처럼 시간과 분 단위로 표시해요.

## 광고

메인 페이지와 차트 페이지에 배너 광고 슬롯을 둬요.
MVP에서는 테스트 광고 그룹 ID를 사용해요.
출시 전 실제 광고 그룹 ID로 바꿔야 해요.

Apps in Toss 광고 SDK가 없는 브라우저 개발 환경에서는 SDK 호출이 실패해도 앱이 흰 화면으로 깨지지 않아야 해요.
