# 찰랑

찰랑은 Apps in Toss에 출시하기 위해 만든 뽀모도로 기반 시간 관리 미니앱입니다.
사용자는 앱을 열자마자 집중 타이머를 시작하고, 현재 구간의 남은 시간과 진행 흐름을 Canvas 물결로 확인해요.

## 한 줄 설명

찰랑은 `집중 -> 짧은 휴식`을 4번 반복한 뒤 `긴 휴식`으로 마무리하는 모바일 타이머예요.

## 문제 정의

일반 뽀모도로 앱은 설정 화면과 부가 기능이 많아 첫 행동까지 시간이 걸릴 수 있어요.
찰랑은 Toss 앱 안에서 바로 열리는 미니앱이므로, 복잡한 탐색 없이 한 손으로 시작, 멈춤, 다음 구간 이동, 기록 확인을 할 수 있어야 해요.

## 대상 사용자

- Toss 앱 안에서 가볍게 집중 시간을 관리하고 싶은 사용자
- 집중, 휴식, 긴 휴식 흐름을 별도 설정 없이 바로 쓰고 싶은 사용자
- 최근 집중 기록을 간단한 차트로 확인하고 싶은 사용자

## 핵심 가치

- 첫 화면에서 타이머를 바로 시작할 수 있어야 해요.
- 앱 내부 커스텀 뒤로가기 없이 Toss 기본 네비게이션을 따라야 해요.
- 모바일 WebView에서 입력 확대, 오버스크롤, safe area 겹침 같은 문제를 피해야 해요.
- 사운드, 햅틱, 물결 진행률이 타이머 상태와 어긋나면 안 돼요.
- 출시 전까지 테스트 광고 ID와 secret 값은 코드와 문서에 직접 노출하지 않아요.

## 현재 상태

2026년 5월 24일 기준으로 동작 가능한 MVP가 구현돼 있어요.
기본 타이머, 세션 시간 조정, 볼륨 표시, 차트, 배너 광고 슬롯, 로컬 저장, 자동 배포 파이프라인, 브랜치 보호 훅이 들어갔어요.

## 주요 진입점

- 저장소: [univdev/charlang](https://github.com/univdev/charlang)
- 앱 등록명: `찰랑`
- Apps in Toss appName: `charlang`
- 로컬 개발 서버: `npm run dev`
- 번들 빌드: `npm run build`
- Apps in Toss 업로드: `npm run deploy`
