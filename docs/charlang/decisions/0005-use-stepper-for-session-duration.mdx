# 세션 시간 조정은 버튼형 stepper로 제공하기

## 상태

채택됨

## 날짜

2026-05-24

## 배경

집중, 짧은 휴식, 긴 휴식 시간은 각각 1분부터 60분까지 조정할 수 있어야 했어요.
하지만 모바일 WebView에서 input이 포커스되면 화면이 확대될 수 있고, Apps in Toss 앱 경험을 해칠 수 있어요.

## 결정

숫자 input 대신 `-`와 `+` 버튼이 있는 다이얼로그를 사용해요.
버튼을 짧게 누르면 1분씩 바뀌고, 0.6초 이상 길게 누르면 cubic-in 느낌으로 점점 빠르게 반복 변경돼요.

## 고려한 대안

- number input 사용
- range slider 사용
- wheel picker 사용
- 별도 설정 페이지 사용

## 선택 이유

1분부터 60분까지의 정수 값은 버튼으로 충분히 제어할 수 있어요.
slider는 정확한 정수 선택이 번거롭고, input은 확대와 키보드 문제를 만들 수 있어요.
다이얼로그는 현재 화면의 맥락을 유지하면서 빠르게 조정할 수 있어요.

## 트레이드오프

큰 값으로 빠르게 이동하려면 길게 누르기 동작이 필요해요.
그래서 반복 입력과 햅틱 피드백을 넣어 조작감을 보완했어요.

## 결과와 후속 작업

세션 박스를 누르면 시간 조정 다이얼로그가 열리고, dim 영역을 눌러도 닫혀요.
진행 중인 구간의 시간을 바꾸면 현재 실행 중인 타이머에는 바로 적용하지 않고 다음부터 적용한다는 안내를 보여줘요.
