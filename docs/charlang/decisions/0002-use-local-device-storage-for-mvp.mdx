# MVP 저장소를 로컬 기기로 제한하기

## 상태

채택됨

## 날짜

2026-05-24

## 배경

처음에는 Toss 유저 식별키 기반 저장도 검토했어요.
하지만 MVP에서 사용자별 서버 저장을 넣으면 권한, 개인정보, 운영 비용, 장애 대응 범위가 커질 수 있어요.

## 결정

MVP에서는 로컬 기기 저장만 사용해요.
볼륨, 자동/수동 진행 모드, 세션별 시간, 타이머 스냅샷, 일자별 통계를 local storage에 저장해요.

## 고려한 대안

- Toss 유저 식별키 기반 서버 저장
- 별도 로그인 기반 동기화 저장
- 저장 없이 앱 실행 중 메모리 상태만 유지

## 선택 이유

찰랑의 MVP 가치는 바로 쓸 수 있는 타이머와 로컬 기록이에요.
서버 저장 없이도 핵심 사용 흐름을 검증할 수 있고, 권한과 비용 부담을 줄일 수 있어요.

## 트레이드오프

기기를 바꾸면 기록이 이어지지 않아요.
앱 데이터가 삭제되면 통계도 사라져요.

## 결과와 후속 작업

Toss 유저 식별키 기반 동기화 저장은 백로그로 남겼어요.
이 기능을 추가할 때는 권한, 개인정보 처리, 저장 비용, 복구 정책을 다시 설계해야 해요.
