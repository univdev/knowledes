# 짧은 휴식 진입 전 전면형 광고를 조건부로 보여주기

## 상태

채택됨

## 날짜

2026-05-27

## 배경

찰랑에는 메인 화면과 차트 화면의 배너 광고가 있었어요.
이후 집중 흐름을 크게 방해하지 않는 선에서 전면형 광고를 넣어야 했어요.
사용자는 10분 이상 집중한 뒤 짧은 휴식으로 2번 들어가는 시점에 광고가 나오기를 원했어요.

## 결정

10분 이상 집중한 뒤 짧은 휴식으로 진입한 횟수를 로컬 기기에 저장해요.
2번째 조건 충족 시점에 전면형 광고를 보여줘요.
자연 종료와 10분 이상 집중한 뒤 스킵한 경우를 모두 포함해요.

자동진행 모드에서는 광고가 닫힌 뒤 짧은 휴식 타이머를 시작해요.
수동진행 모드에서는 광고가 닫힌 뒤 짧은 휴식 대기 상태를 보여주고, 사용자가 직접 시작하게 해요.
광고가 표시되는 동안 틱톡음이 나지 않도록 광고 표시 직전에 틱톡 루프를 멈춰요.

## 고려한 대안

- 짧은 휴식에 들어간 즉시 타이머를 계속 흐르게 하고 광고만 덮기
- 모든 짧은 휴식 진입마다 광고 보여주기
- 집중 종료 직후가 아니라 휴식이 끝난 뒤 광고 보여주기

## 선택 이유

광고가 떠 있는 동안 휴식 시간이 줄어들면 사용자가 손해를 보는 느낌을 받을 수 있어요.
그래서 자동진행에서는 광고가 닫힌 뒤 휴식 시간을 시작하게 했어요.
수동진행에서는 원래 사용자가 직접 시작하는 흐름이므로, 광고 종료 뒤 대기 상태를 유지하는 편이 자연스러워요.

조건을 2번째 짧은 휴식 진입으로 둔 것은 첫 집중 직후부터 광고가 뜨는 부담을 줄이기 위해서예요.

## 트레이드오프

전면형 광고는 Apps in Toss 지원 버전과 실제 앱 환경에 의존해요.
일반 브라우저나 미지원 버전에서는 광고를 보여줄 수 없으므로, 이 경우 타이머 흐름을 막지 않아야 해요.

전면형 광고 그룹 ID는 출시 전 실제 운영 값으로 교체해야 해요.

## 결과와 후속 작업

찰랑 PR #7에서 조건부 전면형 광고와 화면별 배너 광고 env 분리를 추가했어요.
출시 전에는 실제 기기에서 광고 표시, 닫기, 틱톡음 정지, 자동진행 재개, 수동진행 대기 상태를 확인해야 해요.
